# 回收站保留时间为 0 时的删除交互

审阅 [retention.html](../../designs/picberth/retention.html)。打开时使用 0 天保留期。设置页可切换为 30 天并保存。图片和设置值均为演示数据。

| 场景 | 操作与预期 |
| --- | --- |
| 0 天，单张或批量 | 图片行和选择栏显示「永久删除」。对话框列出文件名或数量，初始焦点在「取消」。取消或按 Escape 保留图片。确认成功后显示「已永久删除」，回收站不出现该图片。 |
| 30 天，单张或批量 | 点击「移到回收站」，用通知里的「撤销」恢复，或从回收站恢复。 |
| 0 天，设置 | 仅修改「操作记录」的保留时间也可保存。回收站仍为 0 天。 |
| 保留策略不可读 | 加 `?state=unavailable`，删除暂不可用，点击「重试」后恢复。 |
| 操作期间策略改变 | 加 `?state=policy-changed`，第一次点击「移到回收站」后报告保留时间变化。图片保留在原处，下一次须点击「永久删除」并确认。 |
| 删除失败 | 加 `?state=delete-error`，第一次确认显示失败，对话框仍可重试。 |

实施时，界面按当前策略决定按钮和确认流程，服务端在执行前核对策略。旧客户端可以继续使用既有 API 语义。现有回收站内的永久删除入口沿用当前交互。
