# PicBerth v0.0.1

首个版本。PicBerth 是自托管、单管理员图床，Go 程序内嵌管理界面，使用 SQLite 和本地磁盘保存数据。

- 图片上传、文件夹管理、搜索、批量操作、回收站与撤销。
- 上传、管理两种令牌权限，支持 curl、PicGo / PicList、ShareX。
- 图片内容校验、缩略图、重复文件处理、操作日志和状态检查。
- 数据快照、恢复及完整性校验。
- 提供 Linux amd64 / arm64、Windows amd64、macOS arm64 压缩包，以及 Linux amd64 / arm64 容器镜像。

首次启动后，使用服务器日志中的一次性初始化代码创建管理员。原生程序默认只监听回环地址；对外使用时通过 HTTPS 反向代理访问。配置和备份方法见 README。

发布附件包含 `SHA256SUMS`，二进制压缩包附带 GitHub 构建证明；容器构建包含 SBOM 和 provenance。项目采用 MIT 许可证。

这是早期版本。请使用本地磁盘存储数据，重要图片保留独立备份。
