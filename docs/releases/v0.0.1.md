# PicBerth v0.0.1

## 中文

PicBerth 首个版本：面向单管理员的自托管图床。Go 程序内嵌管理界面，使用 SQLite 和本地磁盘保存数据。

### 功能

- 图片上传、文件夹管理、搜索、批量操作、回收站与撤销。
- 上传和管理两种令牌权限，支持 curl、PicGo / PicList、ShareX。
- 图片内容校验、缩略图、重复文件处理、操作日志和状态检查。
- 数据快照、恢复及完整性校验。

### 下载与部署

- 原生程序：Linux AMD64 / ARM64、Windows AMD64、macOS ARM64。
- Docker 镜像：`ghcr.io/dejavumoe/picberth:v0.0.1`，支持 Linux AMD64 / ARM64。
- 压缩包包含程序与 MIT 许可证；使用 `SHA256SUMS` 校验下载文件，并验证 GitHub 构建证明。容器镜像包含 SBOM 和构建来源证明（provenance）。

```sh
docker pull ghcr.io/dejavumoe/picberth:v0.0.1
```

首次启动后，使用服务器日志中的一次性初始化代码创建管理员。原生程序默认只监听回环地址；对外服务请配置 HTTPS 反向代理。配置和备份步骤见仓库 README 与 `deploy/` 示例。

### 注意事项

这是早期版本。请使用本地磁盘存储数据，并为重要图片保留独立备份。项目采用 MIT 许可证。

## English

The first release of PicBerth, a self-hosted image hosting service for a single administrator. The Go binary embeds the management UI and stores data in SQLite and on local disk.

### Features

- Image uploads, folders, search, bulk operations, trash, and undo.
- Separate upload and management token permissions, with support for curl, PicGo / PicList, and ShareX.
- Image content validation, thumbnails, duplicate handling, audit logs, and status checks.
- Data snapshots, restoration, and integrity checks.

### Downloads and deployment

- Binaries: Linux AMD64 / ARM64, Windows AMD64, and macOS ARM64.
- Docker image: `ghcr.io/dejavumoe/picberth:v0.0.1`, supporting Linux AMD64 / ARM64.
- Archives contain the binary and MIT license. Verify downloads against `SHA256SUMS` and verify their GitHub build attestations. Container images include an SBOM and build provenance.

```sh
docker pull ghcr.io/dejavumoe/picberth:v0.0.1
```

After the first startup, create the administrator using the one-time setup code in the server logs. The standalone binary listens on the loopback interface by default. Configure an HTTPS reverse proxy for external access. See the repository README and `deploy/` examples for configuration and backup instructions.

### Important notes

This is an early release. Store data on local disk and keep independent backups of important images. PicBerth is licensed under the MIT License.
