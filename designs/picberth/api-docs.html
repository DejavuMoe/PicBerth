PicBerth
认证 上传 图片 文件夹 错误 频率限制 客户端

API 文档

令牌 OpenAPI
认证 上传 图片 文件夹 错误 频率限制 客户端
地址
https://pics.example.com/api/v1
格式
JSON（UTF-8），上传使用 multipart/form-data

认证

在请求头中带上令牌。令牌不能放在查询字符串里。

Authorization: Bearer pb_…
权限允许
上传上传图片；只能读取自己上传的图片
管理读取、上传、重命名、移动、删除图片；创建、重命名、移动、删除文件夹
 
curl -H "Authorization: Bearer pb_…" \
      "https://pics.example.com/api/v1/images?limit=2"

上传

POST /api/v1/images 上传 上传一张图片
字段类型说明
file文件必填，图片文件
folder文本文件夹路径，例如 旅行/2026；省略时放在根目录；文件夹不存在时返回 404
 
curl -H "Authorization: Bearer pb_…" \
      -F file=@image.png \
      -F folder=旅行/2026 \
      https://pics.example.com/api/v1/images

图片

GET /api/v1/images 管理 列出图片
GET /api/v1/images/{id} 管理 获取图片
PATCH /api/v1/images/{id} 管理 重命名或移动图片
DELETE /api/v1/images/{id} 管理 移到回收站
POST /api/v1/images/batch 管理 批量移动、移到回收站、恢复，最多 500 张
查询参数取值
folder文件夹路径；空值表示根目录；带 q 或筛选时包含子文件夹
q文件名、ID 或 SHA-256 前缀
formatjpeg png gif webp avif，可重复
sourceweb cli token:<id>，可重复
since untilRFC 3339 时间
sortnew old large small name
limit cursor1 到 200，默认 60；nextCursor 翻页
 
curl -X PATCH \
      -H "Authorization: Bearer pb_…" \
      -H "Content-Type: application/json" \
      -d '{"folder": "旅行/2026/云南"}' \
      https://pics.example.com/api/v1/images/7k2m9q4xw8bd3f6hz1ca
curl -X POST \
      -H "Authorization: Bearer pb_…" \
      -H "Content-Type: application/json" \
      -d '{"action": "move", "ids": ["7k2m9q4xw8bd3f6hz1ca"], "folder": ""}' \
      https://pics.example.com/api/v1/images/batch

文件夹

GET /api/v1/folders 管理 列出全部文件夹
POST /api/v1/folders 管理 创建文件夹
PATCH /api/v1/folders/{id} 管理 重命名或移动文件夹
DELETE /api/v1/folders/{id} 管理 删除空文件夹
层数
最多 3 层，例如 旅行/2026/云南
名称
1 到 64 个字符，不含 / 和 \，同一层不能重名
删除
文件夹里有图片或子文件夹时返回 folder-not-empty
链接
移动图片和文件夹不会改变图片链接
curl -X POST \
      -H "Authorization: Bearer pb_…" \
      -H "Content-Type: application/json" \
      -d '{"name": "云南", "parent": "旅行/2026"}' \
      https://pics.example.com/api/v1/folders
HTTP/1.1 201 Created

    {
      "id": "3",
      "name": "云南",
      "path": "旅行/2026/云南",
      "parent": "旅行/2026",
      "imageCount": 0
    }

错误

HTTP/1.1 409 Conflict
    Content-Type: application/problem+json

    {
      "type": "urn:picberth:problem:folder-not-empty",
      "title": "Folder not empty",
      "status": 409,
      "detail": "The folder contains images or folders.",
      "code": "folder-not-empty"
    }
code状态含义
validation400请求或字段无效
unauthorized401令牌缺失、无效或已吊销
forbidden403令牌权限不足
not-found404图片或文件夹不存在
conflict409当前状态不允许该操作
folder-exists409同一层已有同名文件夹
folder-not-empty409文件夹不为空
folder-depth422超过 3 层
too-large413超过单文件上限
unsupported-format415不支持的格式
invalid-image422图片已损坏
rate-limited429超过频率上限

频率限制

上传每分钟最多 60 次。超出时返回 429，Retry-After 为等待的秒数。

HTTP/1.1 429 Too Many Requests
    Retry-After: 12
    Content-Type: application/problem+json

    { "code": "rate-limited", "status": 429 }
